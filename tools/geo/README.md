# Geo tools

Downloaded the data source from https://catalogue.data.wa.gov.au/dataset/?res_format=WMS&tags=suburbs and renamed.

Place `wa-suburbs.geojson` in this folder after downloading a Western Australian suburb/locality boundary dataset (for example, WA Suburb/Locality Boundaries or ABS State Suburbs).
The file should use an open licence such as CC BY 4.0; ensure the site footer includes attribution when the data goes live.

`wa-suburbs.sample.geojson` is a small sample to make the build script runnable in CI and local development; the real dataset should not be committed.
